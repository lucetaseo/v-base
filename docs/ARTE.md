# 아르떼(조명) 요구사항 — 진행 상황 · 받아야 할 자료

요구사항 문서(lighting_business_system_requirements.html)를 기준으로, 무엇이 되었고 무엇을 아르떼에서 받아야 하는지 정리합니다.
기능은 모두 **업체별 기능 스위치**로 켜고 끕니다 (운영자: 업체/계정관리 → [수정/연장] → 기능 켜기/끄기).

## 1. 된 것

| 기능 | 기능 스위치 | 비고 |
|---|---|---|
| 시공 1~4차 일정 · 회차별 시공 사진 (사진마다 품목·공간·특이사항) | `stepPhotos` | 기사·사무실 모두 올림 |
| 시공 사진 정리 (기간별 ZIP 내려받기 → 서버에서 지우기) | `photoArchive` | 설정 > 시공 사진 정리 |
| 입금 확인자 · 검수(점검 완료) · 주 연락처 · 세대 링크 · 기사 프로필 | 각 기능 | |
| 고객 확인 페이지: 시공 달력 · 상담 버튼 | `customerHelp` | 카카오톡 상담 주소·상담 시간은 업체 정보에 입력 |
| **시공 도면 편집**: 도면 파일(그림·PDF·PPT) 올리기, 조명 아이콘 배치·이동·삭제, 제품 연결, 범례, 도형·선·화살표·글자 | `drawings` | PPT 는 슬라이드에 붙인 그림만 꺼냄. 도형으로 그린 도면은 PDF 로 저장해서 올리기 |
| **고객 도면 보기**: 아이콘을 누르면 제품 사진·이름·수량·사양 | `customerDrawings` | 상품관리에서 제품 사양·사진 입력 |
| **계약서 스캔(OCR)**: 종이 계약서 사진 → AI 가 계약 등록 칸 채우기 → 사람이 확인 후 저장 | `contractScan` (기본 꺼짐) | 아래 3번 — 키가 있어야 동작 |
| **거래명세서** (기본 틀): 계약 상세 → [거래명세서] → 인쇄 / PDF 저장 | `statement` (기본 꺼짐) | 아래 4번 — 양식 샘플 받으면 맞춤 |

## 2. 아르떼에서 받아야 할 자료 (체크리스트)

- [ ] **거래명세서 양식 샘플** (지금 쓰는 종이/엑셀 양식 1장) — 칸 배치·문구·도장 자리
- [ ] **사업자 정보**: 상호, 대표자, 사업자등록번호, 사업장 주소, 업태, 종목, 대표 전화 → 운영자가 업체 정보에 입력 (거래명세서 공급자 칸)
- [ ] **입금 계좌** (거래명세서·안내에 넣을지) — 지금은 업체 정보에 계좌 칸이 없음, 받으면 추가
- [ ] **부가세 방식**: 계약 금액이 부가세 포함인지 별도인지 (거래명세서 기본값)
- [ ] **도장(직인) 이미지** — 거래명세서에 찍을지
- [ ] **제품 사진·사양** (자주 쓰는 조명 제품) → 상품관리에서 등록 (고객 도면 보기에 보임)
- [ ] **도면 샘플** (실제 PPT·PDF 1~2개) — PPT 에서 도면 그림이 잘 꺼내지는지 확인
- [ ] **종이 계약서 샘플 사진** 5~10장 (개인정보는 가려도 됨) — 스캔 정확도 확인·지시문 다듬기
- [ ] **자재 기준표** — 전달하기로 함
- [ ] **알림톡 템플릿** (시공 시작·종료) — 미팅 후 템플릿 심사 결과에 따라
- [ ] **카카오톡 상담 주소 · 상담 시간** — 고객 상담 버튼

## 3. 계약서 스캔(OCR) 켜는 법

1. Anthropic(Claude) API 키 발급 → **Vercel 환경변수 `ANTHROPIC_API_KEY`** 에만 넣기 (코드·채팅에 넣지 않음)
2. 운영자가 아르떼 업체의 기능 스위치 `계약서 스캔` 켜기
3. 계약 등록 화면 맨 위 [📷 종이 계약서 스캔으로 채우기]

- 저장하지 않습니다. AI 가 읽은 값을 보여 주고(확실하지 않은 칸은 노란색 '확인 필요'), 사람이 고친 뒤 [양식에 넣기] → 평소처럼 [저장].
- 예상 정확도: 인쇄된 글자 95% 이상, 손글씨 80~90% (숫자·전화번호가 가장 헷갈림) → 확인 단계 필수.
- 비용: 사진 1장당 대략 50~100원 (Claude Opus 5.5 — 사진 크기·글씨 양에 따라 다름). 한 달 100건이면 5천~1만 원 정도.
- **개인정보**: 계약서 사진(고객 이름·연락처·주소)이 Anthropic 으로 보내져 읽힙니다. 고객 안내·동의 문구(개인정보 처리 위탁)를 계약서에 넣는 것을 권장합니다.
- 한 번에 1장. 여러 장짜리 계약서는 첫 장(고객·금액이 있는 장)만 읽힘 — 필요하면 여러 장 읽기로 늘림.

## 4. 거래명세서 — 지금 틀 · 맞출 것

- 지금: 공급자(업체 정보) / 공급받는자(계약자·연락처·현장·계약일) / 합계금액(한글·숫자) / 품목 줄(품목·내용·수량·단가·공급가액·세액) / 할인 줄 / 입금액·잔액 / 작성일 고르기 / 부가세 포함 켜고 끄기.
- 금액이 보이는 직원(계약 금액 권한)에게만 버튼이 보입니다.
- 양식 샘플을 받으면: 칸 배치·문구, 도장, 계좌, 공급자/공급받는자용 2장 인쇄 여부 등을 맞춥니다.

## 5. 정해지지 않은 것 (미팅·확인 후)

| 항목 | 상태 |
|---|---|
| 시공 시작·종료 알림톡 | 템플릿 심사 후 가능한 것 알려 주기로 |
| 별도 자재 요청 | 아르떼가 뜻하는 바 확인 필요 |
| 사진 기반 정산 · 기사별/계약별 정산 기준 | 미팅에서 논의 |
| 배송 상태 관리 | 새 기능 — 미정 |
| 세금계산서 | 과하다고 미팅에서 말할 예정 |
| PG(카드결제) | 토스페이먼츠 등 가맹점 심사 1~2주 + 개발 며칠 |
| 고객 SMS 인증 | 문자 서비스(솔라피 등) 가입 하루 + 개발 1~2일. 토스 본인인증은 별도 계약 |
| 링크 만료 · 접근 기록 | 미팅에서 정하기로 |
